Add app with four tabs (Running, Installed, Tracked, Browse…) using the icon buttons (Track closed eye, game type gamepad, merge layers, stop eye, "Not this one" slashed eye), search, A–Z rail, "N added this session". Per-app settings (name, Game type, Background, icon, merged apps, About, Stop tracking, Clear history) opened by double-click on a Tracked row. Merge into app with a tab per device, the filter, the preview line and the "Suggested" banner. Clear history and Stop need explicit confirmation; nothing is deleted otherwise.

Done when: these screens match the canvas boards and merging a Mac app with a Windows app works against a snapshot from the other device.
